# Mistral Small 4

**Mistral Small 4**, released in March 2026, unifies instruction following, reasoning, multimodal understanding, and agentic coding.

It is an Apache-2.0 MoE model with 119B total parameters, 6B active expert parameters per token, 128 experts with four selected, and a 256K context.

Configurable reasoning lets applications choose fast answers or deeper analysis. Text and image input make one checkpoint useful for chat, documents, code, and visual tasks.
