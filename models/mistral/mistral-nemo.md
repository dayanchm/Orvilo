# Mistral NeMo

**Mistral NeMo**, released in July 2024 with NVIDIA, is a 12B dense model with a 128K context window.

It introduced the Tekken tokenizer, designed for efficient multilingual and code tokenization, and was trained with quantization awareness for effective FP8 inference. Base and instruction checkpoints are Apache 2.0 licensed.

NeMo targets a practical middle ground: stronger capability than small local models while remaining much easier to deploy than frontier-scale systems.
