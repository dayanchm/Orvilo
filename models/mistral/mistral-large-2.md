# Mistral Large 2

**Mistral Large 2**, released in July 2024, is a 123B dense model with a 128K context window.

It improved code generation, mathematics, multilingual output, instruction following, and function calling. Mistral released weights under the Mistral Research License, allowing research and non-commercial use while commercial deployment required separate terms.

The model emphasized concise responses and reduced hallucination, but it remained a very large dense checkpoint to self-host.
