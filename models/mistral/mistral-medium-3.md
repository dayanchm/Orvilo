# Mistral Medium 3

**Mistral Medium 3**, released in 2025, is a frontier-class model positioned between Small and Large for enterprise deployment.

It supports text and image input, coding, tool use, long documents, and agentic workloads while targeting a better performance-to-cost ratio than the largest models. Later Medium 3.x revisions improved these capabilities.

Mistral does not publish a fixed parameter count for this commercial family; exact API versions should be recorded for reproducibility.
