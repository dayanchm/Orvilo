# Mistral 7B

**Mistral 7B**, released in September 2023, is a compact open-weight decoder Transformer. It uses grouped-query attention and sliding-window attention to reduce inference cost while retaining useful local context.

Base and instruction-tuned checkpoints were released under Apache 2.0. The model demonstrated that a carefully designed 7B model could outperform larger earlier open models on many tasks.

It became the architectural starting point for Mistral's later dense and Mixtral models.
