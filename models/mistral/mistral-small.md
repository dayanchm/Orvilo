# Mistral Small

**Mistral Small** began as Mistral's efficient commercial model tier for low-latency text generation, classification, retrieval-assisted answers, and function calling.

The name has covered several dated API checkpoints, so it should not be treated as one fixed architecture. Later open releases—especially Small 3 and Small 4—made the family more clearly defined and self-hostable.

For reproducible applications, record an exact model identifier rather than the moving “Small” alias.
