# Mistral Small 3

**Mistral Small 3**, released in January 2025, is a latency-optimized 24B dense model under Apache 2.0.

It targets common chat, instruction-following, coding, and local-deployment workloads. A relatively shallow architecture reduces time per forward pass, prioritizing fast responses rather than explicit long reasoning.

Later 3.1 updates added vision and a longer 128K context, but the original Small 3 release was primarily a text model.
