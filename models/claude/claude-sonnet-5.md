# Claude Sonnet 5

**Released:** June 2026

## Overview

Claude Sonnet 5 delivers fifth-generation capability for coding, agents, and professional work at scale.

## Architecture and Capabilities

It upgrades Sonnet 4.6, adds selectable effort levels, and uses an updated tokenizer. It remains positioned as the efficient frontier tier.

## Best Fit

It is a current default candidate for high-volume coding, tool use, knowledge work, and agents.

## Limitations and Lifecycle

Tokenizer changes can increase token counts for the same input. Re-evaluate budgets, prompts, safeguards, and latency during migration.
