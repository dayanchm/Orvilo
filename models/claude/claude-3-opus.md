# Claude 3 Opus

**Released:** March 2024

## Overview

Claude 3 Opus was the highest-capability model in the original Claude 3 family.

## Architecture and Capabilities

It combined text and image understanding with a 200K context window and emphasized complex analysis, research, coding, and nuanced generation.

## Best Fit

Opus established Anthropic's premium tier: maximum intelligence where latency and price are secondary.

## Limitations and Lifecycle

It is a retired model and should not be selected for new API integrations.
