# Claude 2

**Released:** July 2023

## Overview

Claude 2 improved coding, mathematics, reasoning, response length, and safety over Claude 1.x.

## Architecture and Capabilities

It launched with a 100K-token context window and became available through both the API and the public claude.ai beta. Anthropic continued using Constitutional AI and preference-based post-training.

## Best Fit

It marked Claude's transition from an early assistant into a practical long-document model.

## Limitations and Lifecycle

Claude 2 is retired. A large context window is capacity, not a guarantee of perfect retrieval or factual accuracy.
