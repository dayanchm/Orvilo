# Claude Mythos 5

**Released:** June 2026

## Overview

Claude Mythos 5 is a restricted model for advanced defensive cybersecurity and life-sciences research.

## Architecture and Capabilities

It shares its underlying model with Fable 5 but is provided with reduced domain safeguards through trusted-access programs. Access is limited to vetted organizations.

## Best Fit

It is intended for qualified researchers whose legitimate work would otherwise be blocked by general-purpose safeguards.

## Limitations and Lifecycle

This is not a normal public API model. Its dual-use capabilities require vetting, monitoring, isolation, and specialized governance.
