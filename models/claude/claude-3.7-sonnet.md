# Claude 3.7 Sonnet

**Released:** February 2025

## Overview

Claude 3.7 Sonnet was Anthropic's first hybrid reasoning model, combining normal responses and extended thinking in one model.

## Architecture and Capabilities

API users could control the thinking-token budget. The 200K-context model substantially improved coding and front-end development, and launched alongside the Claude Code research preview.

## Best Fit

It is the bridge between standard chat models and later agentic Claude 4 systems.

## Limitations and Lifecycle

The model is retired. Extended reasoning can still be wrong and consumes output tokens, time, and money.
