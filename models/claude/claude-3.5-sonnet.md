# Claude 3.5 Sonnet

**Released:** June 2024; updated October 2024

## Overview

Claude 3.5 Sonnet delivered frontier-level reasoning and coding at the Sonnet price and speed tier.

## Architecture and Capabilities

It supports vision and 200K context. The October update improved coding and introduced public-beta computer use, allowing applications to provide screenshots and execute mouse or keyboard actions.

## Best Fit

It was influential for software engineering, visual analysis, and early computer-using agents.

## Limitations and Lifecycle

Computer use was experimental and vulnerable to mistakes and prompt injection. The model is now retired.
