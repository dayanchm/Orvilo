# Claude 2.1

**Released:** November 2023

## Overview

Claude 2.1 doubled the context window to 200K tokens and targeted greater honesty in enterprise workloads.

## Architecture and Capabilities

Anthropic reported fewer false statements and improved comprehension over long documents. The API added system prompts and beta tool-use capabilities around this period.

## Best Fit

It was useful for document analysis, summarization, and early enterprise agents, but has since been retired.

## Limitations and Lifecycle

Long inputs can contain conflicting evidence or prompt injection. Applications must still validate claims and tool requests.
