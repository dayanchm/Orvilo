# Claude Opus 4.5

**Released:** November 2025

## Overview

Claude Opus 4.5 advanced Anthropic's premium tier across coding, agents, computer use, and professional workflows.

The hybrid-reasoning vision model supports 200K context, tool use, and stronger defenses against prompt injection than earlier releases.

It targeted difficult codebase work, complex research, and agents where accuracy matters more than price or latency.

Prompt injection is reduced, not solved. Treat websites, documents, and tool output as untrusted.
