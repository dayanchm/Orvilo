# Claude Opus 4.1

**Released:** August 2025

## Overview

Claude Opus 4.1 was an incremental upgrade focused on agentic tasks, real-world coding, and reasoning.

## Architecture and Capabilities

It preserved the Opus 4 interface and pricing while improving precision on multi-file code changes and research workflows.

## Best Fit

The release offered an easier migration for applications already using Opus 4.

## Limitations and Lifecycle

It is retired. Incremental model upgrades can alter tool choices and output style, so regression evaluation remains necessary.
