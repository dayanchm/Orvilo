# Claude 3.5 Haiku

**Released:** October 2024

## Overview

Claude 3.5 Haiku raised the capability of Anthropic's fast, efficient tier, particularly for coding and tool use.

## Architecture and Capabilities

The model supports a 200K context and text input/output. Unlike Claude 3 Haiku, it was not a vision model in the Anthropic API.

## Best Fit

It fit responsive assistants, classification, extraction, and high-volume coding support.

## Limitations and Lifecycle

It is retired. Do not infer image support merely from the Claude 3.5 family name.
