# Claude 3 Sonnet

**Released:** March 2024

## Overview

Claude 3 Sonnet balanced intelligence, speed, and cost between Haiku and Opus.

## Architecture and Capabilities

The model accepts text and images, supports 200K context, and improved analysis, coding, multilingual work, and refusal accuracy over Claude 2.x.

## Best Fit

It served as the general-purpose middle tier of the original Claude 3 family.

## Limitations and Lifecycle

The model is retired; later Sonnet releases provide stronger coding, reasoning, and tool use.
