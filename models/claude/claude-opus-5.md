# Claude Opus 5

**Released:** July 2026

## Overview

Claude Opus 5 is Anthropic's high-capability general model for coding, agents, computer use, science, and professional work.

## Architecture and Capabilities

It supports effort controls and improves efficiency, alignment, and long-horizon execution over Opus 4.8. Anthropic positions it below the restricted Mythos tier in certain high-risk dual-use capabilities.

## Best Fit

Choose it for difficult generally available workloads when Sonnet's lower cost is less important than depth and reliability.

## Limitations and Lifecycle

It can still take incorrect or hard-to-reverse actions. Constrain tools and consult the current API lifecycle page.
