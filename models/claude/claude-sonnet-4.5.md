# Claude Sonnet 4.5

**Released:** September 2025

## Overview

Claude Sonnet 4.5 strengthened coding, computer use, reasoning, mathematics, and long-running agents.

## Architecture and Capabilities

The 200K-context hybrid-reasoning model improved tool execution and prompt-injection robustness. Anthropic paired it with Agent SDK, memory, and context-management capabilities at the platform layer.

## Best Fit

It became a strong default for software engineering and interactive agents.

## Limitations and Lifecycle

Model capability does not remove computer-use risks. External content remains untrusted and consequential actions need approval.
