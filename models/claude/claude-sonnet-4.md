# Claude Sonnet 4

**Released:** May 2025

## Overview

Claude Sonnet 4 brought stronger coding, reasoning, tool use, and agent behavior to Anthropic's balanced tier.

## Architecture and Capabilities

It supports hybrid reasoning, vision, a 200K standard context, and long-running tool workflows. It launched with Claude Opus 4 as part of the Claude 4 generation.

## Best Fit

It suited production coding agents and general knowledge work where Opus-level cost was unnecessary.

## Limitations and Lifecycle

The original Sonnet 4 API model is retired. Use a supported successor and retest prompts and tool behavior.
