# ChatGLM3-6B

**Released:** October 2023

## Overview

ChatGLM3 moved beyond chat toward tool use and agent-oriented applications.

## Architecture and Training

The 6B family improved instruction following and introduced structured function calling, code execution demos, and an agent format, while retaining a 32K context checkpoint.

## Best Fit

Use it for lightweight bilingual assistants, tool-calling experiments, and local agents.

## Limitations

Applications must validate tool arguments and sandbox execution. The model predates the capabilities of GLM-4 and later releases.
