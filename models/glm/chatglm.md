# ChatGLM-6B

**Released:** March 2023

## Overview

ChatGLM-6B adapted GLM into a compact bilingual conversational model.

## Architecture and Training

The 6.2B model uses the GLM architecture and quantization options that reduce local memory requirements. It was tuned for Chinese-English dialogue.

## Best Fit

Use it for reproducing early compact bilingual assistants or low-cost experimentation.

## Limitations

The original 2K context, older alignment, and custom modeling code are limitations; newer ChatGLM versions are stronger defaults.
