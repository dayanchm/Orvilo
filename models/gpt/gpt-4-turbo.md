# GPT-4 Turbo

**GPT-4 Turbo**, introduced in late 2023, was an optimized GPT-4 generation with a **128K context window**, lower API cost, and newer training knowledge than the original GPT-4 releases.

It improved developer-facing features such as function calling, JSON mode, reproducible outputs through seeds, and vision support in later preview versions. The larger context made it possible to process long documents or substantial code, although maximum context never guaranteed perfect recall.

GPT-4 Turbo is now a legacy/deprecated API model. Its historical role was bridging the original GPT-4 family and the natively multimodal GPT-4o generation.
