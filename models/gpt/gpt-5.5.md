# GPT-5.5

**GPT-5.5** is an OpenAI model generation for coding and professional work. The family includes a standard model and **GPT-5.5 Pro**, which spends more computation for harder and more precise responses.

It develops the GPT-5 direction: configurable reasoning, strong instruction following, multimodal image understanding, and tool-driven workflows. Typical uses include software engineering, document work, analysis, and multi-step professional tasks.

OpenAI does not publish a parameter count. API capabilities and availability should be checked against a dated model snapshot because aliases can change.
