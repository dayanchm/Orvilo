# GPT-4.1

**GPT-4.1**, released in 2025, is a non-reasoning model family focused on coding, literal instruction following, tool use, and long context.

## Family

- GPT-4.1 for maximum capability
- GPT-4.1 Mini for balanced speed and cost
- GPT-4.1 Nano for high-throughput simple tasks

GPT-4.1 supports a **1M-token context window** and low latency without a hidden reasoning step. It works with function calling, structured outputs, web and file search, code interpreter, image input, and remote MCP tools.

It is highly steerable but can follow poor or conflicting instructions too literally. Clear prompts and application-specific evaluations remain essential.
