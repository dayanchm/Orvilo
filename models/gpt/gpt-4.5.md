# GPT-4.5

**GPT-4.5 Preview**, released in 2025, explored scaling unsupervised learning rather than explicit reasoning. It emphasized broad knowledge, natural conversation, pattern recognition, writing, and reduced hallucination relative to earlier GPT-4 models.

GPT-4.5 was a large, compute-intensive preview model rather than a reasoning model. It supported text and image input, tool use, and a 128K context window, but was expensive to serve.

The API preview was later deprecated. Its historical value was showing the strengths and costs of scaling general-purpose pretraining before the GPT-5 reasoning generation.
