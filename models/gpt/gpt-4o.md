# GPT-4o

**GPT-4o**, released in 2024, introduced the “omni” generation. It was designed to process text, images, and audio with lower latency than a pipeline of separate specialist models.

The text API model supports a 128K context window and image input. Realtime and audio variants enabled speech-to-speech interaction, interruption handling, and expressive voice experiences.

```text
Text / image / audio → One multimodal family → Text / audio responses
```

GPT-4o balanced intelligence, speed, and multimodality, but different API variants support different modalities. The name alone does not imply that every endpoint accepts or produces audio.
