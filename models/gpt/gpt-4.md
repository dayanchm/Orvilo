# GPT-4

**GPT-4**, released in 2023, improved reasoning, instruction following, coding, and safety over GPT-3.5. It was also OpenAI's first GPT generation publicly presented with image-and-text input capability.

OpenAI did not disclose its parameter count or detailed architecture. GPT-4 was evaluated on professional and academic benchmarks and offered 8K and 32K context variants.

```text
Text + optional image → Multimodal model → Text response
```

GPT-4 made multimodal analysis and stronger reliability central to the GPT line, but it could still hallucinate, make reasoning mistakes, and lack knowledge of recent events without tools.
