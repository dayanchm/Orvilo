# GPT-3.5

**GPT-3.5** refers to the generation between GPT-3 and GPT-4, including models optimized for instruction following and conversation. It powered the original public release of ChatGPT in November 2022.

GPT-3.5 Turbo brought chat-oriented behavior to the API at lower cost and latency than GPT-4. Later variants supported larger context windows and structured features such as function calling and JSON output.

Its main contribution was accessibility: capable conversational AI became practical for large-scale products. However, GPT-3.5 was weaker than GPT-4 in complex reasoning, instruction reliability, factual accuracy, and difficult coding.

GPT-3.5 Turbo is now a legacy/deprecated API family; new applications should use a currently supported model rather than assuming old aliases remain stable.
