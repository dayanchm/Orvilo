# GPT-6 Astra

**GPT-6 Astra** is OpenAI's flagship model for difficult end-to-end work, including complex reasoning, coding, computer use, research, and document creation.

## Key Capabilities

- 1,050,000-token context and 128,000 maximum output tokens
- Reasoning effort: low, medium, high, xhigh, or max
- Text and image input with text output
- Web and file search, code interpreter, hosted shell, computer use, MCP, skills, and tool search
- Async tool calling and mid-turn steering

Astra is designed for long workflows that cross code, browsers, and professional software. Applications still execute tools and must enforce permissions, validate actions, and handle failures.

OpenAI does not publish its parameter count, and the API model does not natively accept audio or video.
