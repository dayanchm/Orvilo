# Llama 3.1

**Llama 3.1**, released in July 2024, added 8B, 70B, and flagship 405B dense models with a **128K context window**.

It expanded multilingual support and improved coding, reasoning, tool use, and synthetic-data generation. The 405B checkpoint was the first frontier-scale openly released Llama model and could act as a teacher for smaller models.

All variants remained text-in/text-out and used grouped-query attention. Their open weights allow customization, but hosting 405B requires substantial distributed infrastructure.
