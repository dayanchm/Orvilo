# Llama 3.3

**Llama 3.3**, released in December 2024, is a 70B multilingual text model with a 128K context window.

It was pretrained on more than 15T tokens and post-trained with supervised fine-tuning and RLHF. Meta focused on bringing performance near the much larger Llama 3.1 405B to a checkpoint that is easier to host.

It supports eight officially listed languages, code, tool use, and assistant-style dialogue. It is text-only; Llama 3.2 vision models remain the relevant choice for image input.
