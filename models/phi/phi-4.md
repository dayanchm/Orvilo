# Phi-4

**Released:** December 2024 onward

## Overview

Phi-4 evolved from a 14B text reasoning model into a collection covering compact deployment, multimodality, and specialized reasoning.

## Architecture and Training

The original Phi-4 emphasizes mathematics and reasoning with a 16K context. Later Mini, Multimodal, Reasoning, and Reasoning Vision variants have different sizes, contexts, and input types.

## Best Fit

Use the base model for general text reasoning, Mini for efficient deployment, Multimodal for image/audio/text, and Reasoning checkpoints for deliberate problem solving.

## Limitations

The family name is not a single specification. Verify the exact checkpoint, prompt format, context, and modality before deployment.
