# Phi-2

**Released:** December 2023

## Overview

Phi-2 scaled the approach to 2.7B parameters and broadened its mix of synthetic and filtered web data.

## Architecture and Training

Microsoft reported training on 1.4 trillion tokens. The base model showed notable reasoning and coding ability for its size, but was not originally safety-aligned as a chat assistant.

## Best Fit

It works well for local experimentation, representation research, and task-specific fine-tuning.

## Limitations

Prompt format matters, the context is about 2K tokens, and generated claims or code require review.
