# Phi-1

**Released:** June 2023

## Overview

Phi-1 demonstrated that a compact 1.3B-parameter model could perform useful Python coding when trained on high-quality data.

## Architecture and Training

Microsoft trained it on filtered web code plus synthetic, textbook-like material. The research emphasized data quality and curriculum over parameter count alone.

## Best Fit

Its strongest intended area is Python code generation and textbook-style exercises. It is a research model rather than a general conversational assistant.

## Limitations

The narrow data mix, short context, and small scale limit factual knowledge and broad language coverage.
