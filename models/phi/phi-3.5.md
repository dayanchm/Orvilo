# Phi-3.5

**Released:** August 2024

## Overview

Phi-3.5 added stronger multilingual, long-context, mixture-of-experts, and vision options.

## Architecture and Training

The collection includes a 3.8B Mini model, a sparse MoE model, and a Vision model. Mini supports up to 128K context and targets multilingual reasoning; Vision supports multiple images and video-frame style inputs.

## Best Fit

Select Mini for compact text use, MoE for higher capacity, and Vision for visual document or image tasks.

## Limitations

Do not assume every Phi-3.5 checkpoint has the same modality, memory requirement, or license conditions.
