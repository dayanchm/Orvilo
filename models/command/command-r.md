# Command R

**Released:** March 2024

## Overview

Command R is a 35B enterprise language model designed around retrieval-augmented generation, grounded answers, citations, and tool use.

## Architecture and Training

Its 128K context supports long documents and retrieved passages. The model was designed for multilingual enterprise workloads and can return citations tied to supplied evidence.

## Best Fit

Choose it for cost-sensitive RAG, search, summarization, and simpler tool workflows. Newer API aliases may point to dated releases.

## Limitations

Grounding reduces but does not remove hallucinations. Validate citations, permissions, and retrieved data; also check Cohere's current deprecation schedule.
