# Command R+

**Released:** April 2024

## Overview

Command R+ is the larger 104B member of the original Command R family, aimed at complex retrieval and agentic workflows.

## Architecture and Training

It retains a 128K context and adds capacity for multi-step tool use, code, and difficult RAG synthesis. Cohere's August 2024 update improved tool decisions, instruction following, throughput, and latency.

## Best Fit

Use R+ when workflow quality matters more than the lower cost and latency of Command R.

## Limitations

The original dated API models have lifecycle and deprecation dates. Treat the model guide as historical and consult current Cohere model availability before production use.
